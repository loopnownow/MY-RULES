权威分层：meme（本机私有） > rules（Cline Rules / MY-RULES） > skills（MY-SKILLS）

0. 分层与敏感边界（最高优先）

  • 分层：meme > rules > skills。冲突时以上层为准。
  • PII / 敏感：仅留在 meme（本机），不写入 rules / skills / 本 HTML。
  • 本文件只收录可进仓的政策红线与分层规则；个人联系方式、凭证、卡号等一律不收录。

1. 稿件正文 vs 批注

  • 图/表占位（如 “[Figure N near here]”）→ 只进 Word 批注，禁止进正文。
  • 内部工作说明（pending source / not in the current files / In the present file 等）→ 只进批注，禁止进正文或回复信正文。
  • 禁止否定列举进正文（was not tested / measured / examined / included 等）；缺口改为「建议下一步做什么」，写在批注里。
  • 伦理、作者、资助核对、数字不一致：只进批注，不进正文。

2. 禁词 / disentangled

  • disentangled 及同类 AI 腔/禁词：按 skills 禁词表与 Rules 常驻政策执行（机器源：ban-terms.yaml）。
  • 例外：引文直引、学科专名词干碰撞、Keep 列表（指南用语与校准 Discussion 模糊语）——细则见 skills，不在此 fork。

3. 清理根目录

  • del_root：D:\0del（非 A 类临时/废料）
  • del_root_a：L:\0del\<project>（A 类项目废料）

4. 交付物类型与落点

  • 按产物类型：报告 / 阶段 QC → HTML；稿件与 Track Changes → DOCX；数据表 → XLSX；用户当轮点名格式则从其点名。
  • 阶段终稿：有子工程只放子工程；无子工程放 Downloads。临时一律 D:\0del\。不另交中间稿或 Downloads 平行副本。

5. 座位与 Track Changes

  • TC 落笔归属：Aitee（05）。Lee（06）只标问题、写批注，默认不自行改稿。
  • Aitor（00）：QC / 路由 / 运维 / 盯梢交接；不是 Word 修订落笔方。
  • 批注与 Track Changes 作者字段写 A；禁止 Grok；禁止黄色填充。

6. 交接盯梢

  • 凡把任务交给 Cline 或 Cursor Agent：仅在该次任务期间盯梢。
  • 每 10 分钟查看该次任务进度（勿等用户问）；任务结束或无活跃外挂即停。
  • 一个任务只交一个执行方。短任务 Aitor 本地做完，不另开 Cursor / Cline。

7. 网络

  • 权威文件：network-security.md（Cline Rules / MY-RULES 同名）。
  • 仅禁止网段、敏感外发、该文件规定须批情形（先交风险清单）；公网不逐次批。
